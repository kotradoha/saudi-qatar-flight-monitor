※ 데이터 출처·판단 방식

  • 공항 폐쇄·운영 여부 → 사우디 민간항공청(GACA) 발표와 공항 NOTAM(항공고시보)을 전한 주요 통신사(Reuters 등)·항공 전문지 보도를 기준으로 합니다. 공식 재개 일정이 없으면 ‘미정’으로 둡니다.
  • 운항 → 항공편 추적 사이트(Flightradar24·Planefinder 등)에서 기체 신호(ADS-B)로 실제 이착륙이 확인된 편만 표시합니다.
  • 결항·일부결항 → 항공사 공지, 언론 보도, 또는 추적 사이트의 결항 표시를 근거로 합니다. 추적 사이트 표시는 항공사 공식 발표가 아니므로 근거 번호로 구분해 두었습니다.
  • 예정 → 항공사 스케줄상 운항 예정이고, 결항 공지·표시가 없는 편입니다. 운항 보장을 뜻하지 않습니다.
  • 대상 노선 → 사우디 각 도시–도하 직항을 운항하는 모든 항공사(카타르항공·사우디아·플라이나스)를 포함합니다. 경유편은 넣지 않았습니다.
